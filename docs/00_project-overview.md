# プロジェクト概要

- 現在のフェーズ：現状分析

## 2. 背景

現在はExcelのPower Queryを利用し、各取引先の月別不良率を集計・グラフ表示している。Excelファイルや参照パスへの依存を減らし、Webブラウザから同じ情報を確認できるようにしたい。

## 3. 解決したい課題

- Excelファイルを開かなければ確認できない
- 参照パスや更新手順が担当者に依存している
- 複数人で同じ最新状態を確認しにくい
- 将来のアラート、商品別分析、自動取込へ拡張しにくい

## 4. アプリの目的

各取引先の月別不良率推移を、正しい集計定義に基づいてWeb上で確認できるようにする。

## 5. 対象ユーザー

| ユーザー | 主な利用目的 | 権限の想定 |
|---|---|---|
| 商品部 | 取引先別の品質傾向確認 | 閲覧 |
| 品質管理担当 | データ更新・内容確認 | 閲覧・更新 |

## 6. 現行業務の概要

ExcelのPower Queryで生データを読み込み、取引先単位・月単位で不良率を集計し、折れ線グラフで推移を確認している。
詳細な入力・加工・出力手順は、現行Excel解析後に更新する。

## 7. MVPの範囲

### MVPに含める

- 指定形式の生データ取込
- 取引先選択
- 対象期間指定
- 月別不良率計算
- 折れ線グラフ表示
- Excelとの集計結果比較

### MVPに含めない

- 自動取込
- LINE WORKS通知
- 不良率アラート
- 商品別・カテゴリ別分析
- 詳細な権限管理
