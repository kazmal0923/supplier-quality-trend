# プロジェクト概要

## 1. 基本情報

- 日本語正式名称：仕入先品質トレンド
- 英語表示名：Supplier Quality Trend
- サブタイトル：仕入先・グループ別 現行不良率推移ダッシュボード
- GitHubリポジトリ名：supplier-quality-trend
- GitHub URL：https://github.com/kazmal0923/supplier-quality-trend.git
- Python内部識別名：supplier_quality_trend
- 開始日：要確認
- 担当者：要確認
- 現在のフェーズ：MVP実装済み・実データ受入前

## 2. 背景

現在はExcelのPower Queryを利用し、各仕入先の月別現行不良率を集計・グラフ表示している。Excelファイルや参照パスへの依存を減らし、正しい現行集計条件に基づく情報をWebブラウザから確認できるようにする。

## 3. 解決したい課題

- Excelファイルを開かなければ確認できない
- 参照パスや更新手順が担当者に依存している
- 複数人で同じ最新状態を確認しにくい
- 将来のアラート、商品別分析、自動取込へ拡張しにくい

## 4. アプリの目的

仕入先ごとの月別現行不良率推移を、正しい現行集計条件に基づいてブラウザから確認できるようにする。

単一の`SHIIRESAKI_ID`と、複数の`SHIIRESAKI_ID`をまとめた仕入先グループを切り替えて閲覧できるようにする。

## 5. 対象ユーザー

| ユーザー | 主な利用目的 | 権限の想定 |
|---|---|---|
| 商品部 | 取引先別の品質傾向確認 | 閲覧 |
| 品質管理担当 | データ更新・内容確認 | 閲覧・更新 |

## 6. 現行業務の概要

ExcelのPower Queryで月次データを読み込み、`SHIIRESAKI_ID`単位・月単位で現行不良率を集計し、折れ線グラフで推移を確認している。
AS-ISの未確認事項は`docs/01_current-state-analysis.md`、MVPのTO-BEデータ仕様は`docs/03_data-specification.md`で管理する。

## 7. MVPの範囲

### MVPに含める

- 月次不良率CSVと仕入先マスタのファイル取込
- 単一仕入先・仕入先グループの切替と検索
- 国内／海外および対象期間の絞り込み
- 月別・期間全体の現行不良率計算
- 最新13か月の折れ線グラフ表示
- 最新月と前年同月の比較
- 目標1％の基準線、警告、集計途中、欠損月の表示
- Pythonバッチによる静的JSON生成と定期更新
- IISによる静的Web配信
- Excelとの集計結果比較

### MVPに含めない

- 基幹システムやBoxからの元ファイル自動取得
- LINE WORKS通知
- 外部通知を伴う不良率アラート
- 商品別・カテゴリ別分析
- 詳細な権限管理

## 8. 将来拡張候補

## 9. 制約

- 利用環境：静的Webを社内IISで配信する。Microsoft Edge、Google Chrome、Mozilla Firefoxの各最新版を対象とする
- ネットワーク：実際のIIS URL、アクセス権は移植時に確認する
- データ保管：Publicリポジトリへ実データ、現行Excel原本、仕入先マスタ原本、生成された本番JSON、実設定、ログを保存しない
- 認証：未確定
- 外部連携：MVPでは対象外
- データベースおよび常駐Pythonサーバーは使用しない

## 10. 用語

| 用語 | 定義 |
|---|---|
| 月別現行不良率 | 同じ対象年月の`HENPIN_SU`合計 ÷ `SYUKKA_SU`合計 |
| 期間全体現行不良率 | 対象期間の`HENPIN_SU`合計 ÷ 対象期間の`SYUKKA_SU`合計。月別不良率の単純平均は使用しない |
| 現行指標 | 返品発生SKUの出荷数だけを分母とする現行業務上の傾向確認指標。仕入先全体の正式な不良率とは異なる |
| 単一仕入先 | 1つの`SHIIRESAKI_ID`を単位として表示する閲覧モード |
| 仕入先グループ | 現在名称の完全一致またはエイリアス設定により複数の`SHIIRESAKI_ID`をまとめた閲覧単位 |
