# テスト記録

ExcelとWebアプリの集計結果を比較する検証データと結果を記録します。

実データや機密情報は保存せず、匿名化した検証データを使用してください。

## MVP実装後のテスト計画

匿名・架空データだけを使用し、少なくとも次を確認する。

### 取込・結合

- 正常な複数月CSV
- 月次CSVのファイル名とUTF-8読込
- CP932の仕入先マスタ
- 必須カラム不足、破損CSV、設定ファイル読込失敗
- 仕入先マスタ未登録と月次名称の暫定表示
- 月次CSVの名称と現在名称の差異

### 仕入先・グループ

- 単一仕入先
- 同一現在名称の複数ID
- エイリアスによるグループ統合
- 名称変更済み仕入先
- エイリアス競合による処理停止

### 集計

- 返品数0
- 出荷数0（表示値は仕様確定後に期待値を定義）
- 不良率100％以上
- 同月・同一仕入先IDの重複行
- 月別現行不良率
- 期間全体現行不良率
- グループの数量合計からの再計算
- 1％境界値（1％ちょうどは目標超過扱い）
- `DEFECTIVE_RATE`と再計算結果の照合

### 期間・表示

- 欠損月
- 当月CSVと「集計途中」表示
- 最新データ月を含む13か月
- 前年同月比較とパーセントポイント差
- 前年同月データなし
- 仕入先未選択、該当データなし、期間不正、生成データ未作成

### 更新・セキュリティ

- 全検証成功後の本番JSON置換
- 更新失敗時の前回正常データ維持
- 手動実行とスケジュール実行の終了動作
- 二重起動防止、再試行、最大実行時間
- Publicリポジトリに本番CSV、仕入先マスタ、実設定、実エイリアス、生成された本番JSON、ログ、機密情報が含まれないこと
- IISの公開対象が`web/`だけであること

具体的な自動テストコマンド、対象ブラウザ、性能試験条件は未確定とする。
