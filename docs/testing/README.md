# テスト記録

ExcelとWebアプリの集計結果を比較する検証データと結果を記録します。

実データや機密情報は保存せず、匿名化した検証データを使用してください。

- 実行可能なアプリコード：あり
- 自動テスト：標準ライブラリ`unittest`
- 構文確認：`compileall`、JavaScriptは`node --check`
- 専用型チェック / Lint：未導入
- ビルド：該当なし（ビルド工程なし）

## MVPテスト計画

匿名・架空データだけを使用し、少なくとも次を確認する。

### 取込・結合

- 正常な複数月CSV
- 月次CSVのファイル名とUTF-8読込
- CP932の仕入先マスタ
- 必須カラム不足、破損CSV、設定ファイル読込失敗
- 仕入先マスタ未登録と月次名称の暫定表示
- 月次CSVの名称と現在名称の差異

### 仕入先・グループ

- 単一仕入先
- 同一現在名称の複数ID
- エイリアスによるグループ統合
- 名称変更済み仕入先
- エイリアス競合による処理停止

### 集計

- `HENPIN_SU`空欄の行除外と警告詳細
- `SYUKKA_SU`空欄の行除外と警告詳細
- 数量の整数表記と整数相当表記（`1.0`・`2.00`）
- 数量の非整数（`1.5`・`0.25`）による行除外と警告
- 数量の非数値・非有限値・負数による行除外
- 項目数不足行の空文字変換、行除外、有効行0件
- 両数量不正時のカラム別警告と1回だけの行除外
- 月次CSV内の有効行0件による更新失敗と前回正常JSON維持
- 当月CSVがヘッダーのみでも処理成功、`EMPTY_CURRENT_MONTH_FILE`警告のJSON出力、前月までの集計生成
- 過去月CSVがヘッダーのみ、または不正行のみで有効行0件の場合の処理失敗
- 当月空CSVのみの場合の処理失敗と前回正常JSON維持
- 当月判定がJST（UTC+9）であること
- 返品数0
- 出荷数0（数量保持、不良率`null`、「算出不可」表示、警告）
- 不良率100％以上
- 同月・同一仕入先IDの重複行
- 月別現行不良率
- 期間全体現行不良率
- グループの数量合計からの再計算
- 1％境界値（1％ちょうどは目標超過扱い）
- `DEFECTIVE_RATE`の絶対差`1E-12`以内の微小誤差
- 明確な`DEFECTIVE_RATE`不一致
- `DEFECTIVE_RATE`空欄時の警告、行保持、数量からの再計算
- `DEFECTIVE_RATE`が集計値へ影響しないこと

### 期間・表示

- 欠損月
- 当月CSVと「集計途中」表示
- 最新データ月を含む13か月
- 前年同月比較とパーセントポイント差
- 前年同月データなし
- 仕入先未選択、該当データなし、期間不正、生成データ未作成

### 更新・セキュリティ

- 全検証成功後の本番JSON置換
- 更新失敗時の前回正常データ維持
- 手動実行とスケジュール実行の終了動作
- 二重起動防止、再試行、最大実行時間
- Publicリポジトリに本番CSV、仕入先マスタ、実設定、実エイリアス、生成された本番JSON、ログ、機密情報が含まれないこと
- IISの公開対象が`web/`だけであること

対象ブラウザはMicrosoft Edge、Google Chrome、Mozilla Firefoxの各最新版とする。性能試験条件は未確定とする。
