# 受入条件

## 1. 判定ルール

- すべてのMust要件を満たすこと
- 指定されたテストデータで期待結果と一致すること
- テスト、ビルド、型チェックが成功すること（存在しない場合は該当なしと理由を記録）
- docsが実装状態と一致すること

## 3. データ取込

- [ ] `YYYY年MM月.csv`をUTF-8で一括読込できる
- [ ] 仕入先マスタをCP932で読み込める
- [ ] 必須カラム不足時は処理を停止する
- [ ] `DEFECTIVE_RATE`を正本にせず、再計算結果との照合に使用する
- [ ] マスタ未登録IDを削除せず、月次名称を暫定表示して警告する
- [ ] エイリアス競合時は処理を停止する

## 4. 集計・計算

- [ ] 月別現行不良率を数量合計から計算できる
- [ ] グループ不良率を各IDの率の平均ではなく数量合計から計算できる
- [ ] 期間全体現行不良率を数量合計から再計算できる
- [ ] 内部計算では丸めず、画面は百分率の小数第2位まで表示する
- [ ] 丸め前の値で1％未満／1％以上を判定する
- [ ] 100％以上も補正せず、警告付きで表示する
- [ ] 重複行は数量を合算し、警告を残す
- [ ] `SYUKKA_SU=0`の行は数量を保持して集計し、合計出荷数0の場合は不良率を`null`として「算出不可」と表示する
- [ ] `HENPIN_SU`・`SYUKKA_SU`は数値へ変換できる有限・0以上・整数の値だけを有効とする
- [ ] `1.0`・`2.00`など数値として整数の値は有効とし、`1.5`・`0.25`など非整数を含む行は集計対象外とする
- [ ] 数量の空欄、非数値、非有限値、負数、非整数を含む行は集計対象外とし、ファイル名、行番号、カラム名、元値を警告へ記録する
- [ ] 両方の数量が不正な行は各カラムの警告を記録し、行の除外は1回だけ行う
- [ ] 実行日（JST）の当月CSVがヘッダー行のみの場合は`EMPTY_CURRENT_MONTH_FILE`警告を残して処理を継続し、最新データ月は有効行がある最新月とする
- [ ] 過去月CSVがヘッダー行のみ、またはデータ行はあるが有効行0件の場合は更新失敗とし、前回正常JSONを維持する
- [ ] 当月CSVにデータ行はあるが全行不正で有効行0件の場合は更新失敗とし、前回正常JSONを維持する
- [ ] 当月の空CSVしかなく有効データがない場合は処理失敗とし、前回正常JSONがあれば維持し、なければダッシュボードJSONを新規生成しない
- [ ] 丸め前の`DEFECTIVE_RATE`と再計算値の絶対差が`1E-12`を超える場合に警告する
- [ ] CSVの`DEFECTIVE_RATE`が集計結果へ影響しない

## 5. 画面

- [ ] 単一仕入先／仕入先グループ／国内／海外合算を切り替えられる
- [ ] 仕入先をチェックボックスで複数選択し、数量合計から再計算できる
- [ ] 国内／海外をまたいで複数選択できる
- [ ] 国内／海外合算が区分内全単一仕入先の数量合計になる
- [ ] IDと現在名称の両方で検索できる
- [ ] 国内／海外、開始月、終了月で絞り込める
- [ ] 最新月と前年同月を比較できる
- [ ] 前年同月がない場合に「前年同月データなし」と表示する
- [ ] 最新データ月が実行月なら「集計途中」と表示する
- [ ] 現行指標の制約注釈を確認できる
- [ ] 仕入先未選択、該当データなし、期間不正、更新失敗、警告、マスタ未登録、欠損月、設定エラー、生成データ未作成を識別できる

## 6. 非機能

- [ ] 認証情報や機密データがGitへ含まれていない
- [ ] 実Excel原本、本番CSV、仕入先マスタ原本、実設定、生成された本番JSON、ログが含まれていない
- [ ] IISでは`web/`だけが公開対象である
- [ ] Apache ECharts本体とライセンスファイルをアプリ内に保持する
- [ ] データベースと常駐Pythonサーバーを使用しない
- [ ] 更新失敗時に前回正常データを維持する
- [ ] タスクを二重起動せず、最大実行時間30分で終了する
- [ ] 開始時刻を逃した場合は可能になり次第実行し、失敗時は10分間隔で最大3回再試行する
- [ ] 対象ブラウザで利用できる
- [ ] 想定データ量で許容時間内に表示される
- [ ] テストとビルドが成功する（存在しない場合は該当なしと理由を記録）

対象ブラウザはMicrosoft Edge、Google Chrome、Mozilla Firefoxの各最新版とする。想定データ量と許容時間は未確定であり、確定後に具体的な判定値を追記する。
