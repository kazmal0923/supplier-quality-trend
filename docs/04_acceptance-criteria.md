# 受入条件

## 1. 判定ルール

- すべてのMust要件を満たすこと
- 指定されたテストデータで期待結果と一致すること
- テスト、ビルド、型チェックが成功すること（存在しない場合は該当なしと理由を記録）
- docsが実装状態と一致すること

## 2. 機能別受入条件

| ID | 対象機能 | 前提 | 操作 | 期待結果 | 状態 |
|---|---|---|---|---|---|
| AC-001 | 生データ取込 | 指定形式のデータがある | 取り込む | 取り込める | 未確認 |
| AC-002 | 取引先フィルター | データ取込済み | 取引先を選択する | 選択した取引先のみ表示される | 未確認 |
| AC-003 | 期間フィルター | データ取込済み | 対象期間を指定する | 指定期間のみ表示される | 未確認 |
| AC-004 | 月別不良率集計 | 定義済みデータ | 集計を確認する | 定義どおり計算される | 未確認 |
| AC-005 | 折れ線グラフ表示 | 集計済み | 画面を表示する | 月別推移が表示される | 未確認 |
| AC-006 | Excel比較 | 検証データがある | 結果を比較する | Excelと一致する | 未確認 |

## 3. データ取込

- [ ] 指定形式の生データを取り込める
- [ ] 必須カラム不足時にエラーを表示する
- [ ] 重複データを定義どおり処理する
- [ ] 不正値を定義どおり処理する

## 4. 集計・計算

- [ ] 月別不良率を定義どおり計算できる
- [ ] 0件・0除算時の表示が定義どおりになる
- [ ] 指定した検証データでExcelの結果と一致する

## 5. 画面

- [ ] 取引先を選択できる
- [ ] 対象期間を指定できる
- [ ] 月別推移を折れ線グラフで表示できる
- [ ] データなし・エラー時の表示が定義どおりである

## 6. 非機能

- [ ] 認証情報や機密データがGitへ含まれていない
- [ ] 実Excel原本・本番CSVが含まれていない
- [ ] 対象ブラウザで利用できる
- [ ] 想定データ量で許容時間内に表示される
- [ ] テストとビルドが成功する（存在しない場合は該当なしと理由を記録）
