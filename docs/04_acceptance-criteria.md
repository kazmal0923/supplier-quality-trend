# 受入条件

## 1. 判定ルール

- すべてのMust要件を満たすこと。
- 指定されたテストデータで期待結果と一致すること。
- テスト、ビルド、型チェックが成功すること。
- docsが実装状態と一致すること。

## 3. データ取込

- [ ] 指定形式のデータを取り込める
- [ ] 必須カラム不足時にエラーを表示する
- [ ] 重複データを定義どおり処理する
- [ ] 不正値を定義どおり処理する

## 4. 集計・計算

- [ ] 計算定義どおりの結果になる
- [ ] 0件・0除算時の表示が定義どおりになる
- [ ] 既存Excel等との比較結果が一致する

## 5. 画面

- [ ] 初期表示が定義どおりである
- [ ] フィルターが正しく動作する
- [ ] データなし・エラー時の表示が定義どおりである

## 6. 非機能

- [ ] 認証情報や機密データがGitへ含まれていない
- [ ] 対象ブラウザで利用できる
- [ ] 想定データ量で許容時間内に表示される
