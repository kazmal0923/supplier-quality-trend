# FEATURE-001 仕入先品質トレンドMVP

## 背景

Excel Power Queryで運用している不良率推移の確認業務を、仕入先品質トレンドとしてWeb化する。

## 目的

仕入先ごとの月別現行不良率推移を、正しい現行集計条件に基づいてブラウザから確認できるようにする。単一の`SHIIRESAKI_ID`と仕入先グループを切り替えて閲覧できるようにする。

## 対象

- 月次不良率CSVと仕入先マスタのファイル読込
- 単一仕入先・仕入先グループの選択、検索、国内海外絞り込み
- 月別・期間全体現行不良率の集計
- 最新13か月と前年同月比較
- 目標1％、異常値、欠損月、集計途中、警告を含む折れ線グラフ
- KPI、詳細表、更新状態、空状態・エラー状態
- Pythonバッチによる静的JSON生成とWindowsタスクスケジューラ更新
- IISによる静的Web配信
- Excelとの一致確認

## 対象外

- LINE WORKS等への外部通知
- 基幹システムやBoxからの元ファイル自動取得
- 商品別・カテゴリ別分析
- 詳細な権限管理
- データベース、常駐Pythonサーバー

## 現行不良率

```text
月別現行不良率 = HENPIN_SUの月別合計 ÷ SYUKKA_SUの月別合計
期間全体現行不良率 = 対象期間のHENPIN_SU合計 ÷ 対象期間のSYUKKA_SU合計
```

月別不良率の単純平均は使用しない。仕入先グループも数量合計から再計算する。

`SYUKKA_SU`には返品が発生したSKUの出荷数だけが含まれるため、本指標は仕入先全体の正式な不良率ではない。MVPでは現行Excelとの一致を優先し、100％を超える値も補正せず警告付きで表示する。

## 仕入先の閲覧

単一仕入先モードでは、次の形式で候補を表示し、IDと現在名称で検索できるようにする。候補の並びは、数字のみの仕入先IDを数値昇順とし、非数字IDはその後ろに文字列順とする。国内／海外は混ぜたまま並べる。

```text
[国内／海外] SHIIRESAKI_ID｜現在の仕入先名
```

仕入先グループモードでは、現在名称の完全一致または`config/supplier-name-aliases.csv`の設定により複数IDをまとめる。同じ別名が複数グループへ登録された場合は処理を停止する。初期エイリアス一覧は未確定とする。

## 初期表示・前年同月比較

- 読み込めた最新データ月を含む13か月を初期表示する
- 最新データ月が実行月なら「集計途中」と表示する
- 最新月と前年同月について、不良率、返品数、出荷数を比較する
- 不良率差はパーセントポイントで表示する
- 前年同月データがない場合は「前年同月データなし」と表示する

## 更新・公開

- Python 3.14の`main.py`で表示用JSONを生成する
- `run.bat`を手動または`scheduled`引数で実行する
- 毎週月曜日午前8時にタスクスケジューラで実行する
- 全検証成功後に本番JSONを置換し、失敗時は前回正常データを維持する
- 静的な`web/`だけをIISで公開する
- Apache EChartsはCDNを使用せず、ライセンスとともにアプリ内へ配置する

## 画面注釈

次の趣旨を情報表示する。初期表示は折りたたみ要約とし、利用者が開くと全文を確認できる。

> 本画面の不良率は、当月に出荷した商品のうち、返品が発生したSKUの出荷数を分母として算出しています。返品が発生していないSKUの出荷数は分母に含まれないため、仕入先全体の正式な不良率とは異なります。現行集計条件に基づく傾向確認用の指標として参照してください。集計条件により、100％を超える場合があります。
