# FEATURE-002 任意複数選択と国内／海外合算

## 背景

MVP（FEATURE-001）では、単一仕入先は1件選択、仕入先グループは名称一致またはエイリアスで事前定義した単位のみ閲覧できる。
実運用では、同一会社が複数IDに分かれる場合にその場でIDを選んで合算したい需要と、国内／海外区分全体の合算不良率を確認したい需要がある。

## 目的

- 仕入先IDをチェックボックスで複数選択し、数量合計から現行不良率を再計算して表示する
- 国内仕入れ／海外仕入れそれぞれについて、区分内の全単一仕入先を数量合計した合算不良率を表示する

## 対象

- 閲覧モード「仕入先（複数選択）」でのチェックボックス複数選択
- 国内／海外をまたいだ複数選択の許可
- 閲覧モード「国内／海外合算」での区分全体合算
- KPI、推移グラフ、月別詳細への合算結果の反映
- 合算は生成済みJSONの月別集計数量をブラウザで合算する（CSV再解析はしない）

## 対象外

- エイリアス設定の自動生成
- 複数選択状態のURL永続化
- バッチ側JSONスキーマ変更
- 既存の仕入先グループ（名称／エイリアス）モードの廃止

## 集計定義

選択した各仕入先（または区分内の全単一仕入先）について、月ごとに次を行う。

```text
月別合算返品数 = 選択対象の当月返品数合計（欠損月は除外）
月別合算出荷数 = 選択対象の当月出荷数合計（欠損月は除外）
月別現行不良率 = 月別合算返品数 ÷ 月別合算出荷数
```

期間全体も数量合計から再計算し、月別率の単純平均は使用しない。
対象すべてが欠損の月は欠損月とする。一部だけ欠損の月は、データがある対象だけを合算する。

## 画面仕様

### 閲覧モード

| 値 | 表示名 | 操作 |
|---|---|---|
| `supplier` | 仕入先（複数選択） | チェックボックス一覧で複数選択。国内／海外またぎ可 |
| `group` | 仕入先グループ | 既存どおり単一選択（名称／エイリアス） |
| `category` | 国内／海外合算 | 区分全体合算を選択 |

### 国内／海外合算

- 候補は区分値（例: 国内仕入れ、海外仕入れ）
- 合算対象は、その区分に属する**すべての単一仕入先**
- 検索や国内／海外フィルターで候補を減らしても、合算範囲は変えない

### 仕入先（複数選択）

- チェックボックス一覧で選択
- **全選択**は、現在表示中（検索・国内／海外フィルター適用後）の候補を追加選択する
- **選択解除**は、選択をすべてクリアする
- 国内／海外フィルターと検索は、表示するチェック候補の絞り込みにのみ使用する
- 選択済みIDはフィルター変更後も可能な範囲で維持する

## 受入条件

- 複数ID選択時、月別・期間全体が数量合計から再計算される
- 国内／海外合算が、区分内全単一仕入先の数量合計と一致する
- 国内／海外をまたいだ複数選択ができる
- 1件選択時も従来どおり表示できる
- 未選択時は空状態を表示する
- 既存の仕入先グループモードが維持される
- 集計式・原子的JSON更新・バッチ入力仕様は変更しない
