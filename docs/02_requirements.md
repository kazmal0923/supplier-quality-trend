# 要件定義（TO-BE）

## 1. 業務要件

| ID | 要件 | 背景・目的 | 優先度 |
|---|---|---|---|
| BR-001 | 各取引先の月別不良率推移をWebで確認できる | Excel依存を減らし、ブラウザから確認できるようにする | Must |
| BR-002 | Excelと同じ検証データで集計結果が一致する | 現行業務と同じ定義で信頼性を担保する | Must |
| BR-003 | 取引先と対象期間を指定できる | 確認したい範囲に絞り込みできるようにする | Must |

## 2. 機能要件

| ID | 機能 | 概要 | MVP対象 |
|---|---|---|---|
| FR-001 | 生データ取込 | 指定形式のデータを取り込む | Yes |
| FR-002 | 取引先フィルター | 取引先を選択して表示を絞り込む | Yes |
| FR-003 | 期間フィルター | 対象期間を指定する | Yes |
| FR-004 | 月別不良率集計 | 定義に基づき月別不良率を計算する | Yes |
| FR-005 | 折れ線グラフ表示 | 月別推移を折れ線グラフで表示する | Yes |
| FR-006 | 不良率アラート | 閾値超過などを通知する | No |

## 3. 非機能要件

### 性能

- 想定データ量・応答時間は現行Excel解析後に定義する（未確定）

### セキュリティ

- 実データ、認証情報、個人情報をGitへ含めない
- 詳細は`docs/08_security-and-data-handling.md`を参照

### 可用性・バックアップ

- 未確定

### 保守性

- 集計定義・除外条件を文書化し、UIへ直書きしない

### 対応環境

- 未確定（対象ブラウザ・社内ネットワーク要件は要確認）

## 4. 利用者と権限

| ロール | 閲覧 | 登録 | 更新 | 削除 | 管理 |
|---|---:|---:|---:|---:|---:|
| 商品部 | Yes | No | No | No | No |
| 品質管理担当 | Yes | 要確認 | Yes | 要確認 | 要確認 |

詳細な権限管理はMVP対象外。

## 5. データ更新方法

- 初期方式：管理者によるCSVまたはExcelアップロード（提案。`docs/decisions/ADR-001_initial-import-method.md`参照）
- 将来方式：自動取込（対象外）
- 更新担当者：品質管理担当（想定）
- 更新頻度：要確認

## 6. エラー時の動作

| ケース | 表示内容 | 記録 | 再実行方法 |
|---|---|---|---|
| 必須カラム不足 | エラーを表示する | 要確認 | データを修正して再取込 |
| 0除算 | 定義どおりの表示（未確定） | 要確認 | 要確認 |
| 不正値 | 定義どおり処理（未確定） | 要確認 | 要確認 |

## 7. 対象範囲

### 対象

- 取引先別の月別不良率推移の確認
- 生データ取込、フィルター、集計、グラフ表示
- Excelとの集計結果比較

### 対象外

- 自動取込
- LINE WORKS通知
- 不良率アラート
- 商品別・カテゴリ別分析
- 詳細な権限管理

## 8. 将来拡張

- 自動取込
- LINE WORKS通知
- 不良率アラート
- 商品別・カテゴリ別分析
- 詳細な権限管理
