## 現時点で確定している方向性

### プロジェクトの目的

単一の`SHIIRESAKI_ID`または複数IDをまとめた仕入先グループについて、月別現行不良率を集計し、推移をグラフで確認できるダッシュボードを構築します。

属人的なExcel確認を減らし、品質状況の変化を継続的に把握できる状態を目指します。

### MVPの基本方向

MVPでは、以下を実装対象とします。

- 月次不良率CSVと仕入先マスタのファイル読込
- 単一仕入先・仕入先グループの選択
- 月別・期間全体現行不良率の数量合計からの再計算
- 最新13か月の推移、前年同月比較、目標線、警告、注釈
- Pythonバッチによる表示用JSON生成と週次更新
- IISによる静的Web配信
- 現行Excelとの集計結果比較

### MVP対象外

以下は、現時点では将来候補とします。

- LINE WORKS等への自動通知
- 外部通知を伴う閾値超過アラート
- 商品別・カテゴリ別の詳細分析
- 基幹システムやBoxからの元ファイル自動取得
- 高度な権限管理
- 定期レポートの自動配信
