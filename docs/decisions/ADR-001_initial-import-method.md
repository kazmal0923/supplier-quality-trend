# ADR-001 MVPのデータ取込方式

- 状態：置換済み

## 背景

共有フォルダの自動監視や基幹システム連携は、ネットワーク権限と実行環境の確認が必要である。

## 当初の提案

MVPでは管理者によるCSVまたはExcelアップロード方式とし、自動取込は将来拡張とする。

## 理由

初期開発の範囲を抑え、集計結果と業務価値の検証を優先するため。

## 置換理由

MVP基本設計では、準備済みの月次CSVと仕入先マスタをPythonバッチで読み込み、表示用JSONを静的生成する方式を採用した。

基幹システムやBoxから元ファイルを自動取得する処理は引き続きMVP対象外だが、フォルダへ配置済みのファイルをWindowsタスクスケジューラで定期処理する。

新しい判断は`docs/decisions/ADR-002_static-generation-and-iis.md`を正とする。
