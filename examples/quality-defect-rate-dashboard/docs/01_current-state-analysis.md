# 現状分析（AS-IS）

## 1. 調査対象

- 対象：品質管理ダッシュボードExcel
- 主な技術：Power Query、ピボット、折れ線グラフ
- 用途：各取引先の月別不良率推移の確認

## 2. 現時点で確認できていること

- Excel Power Queryで生データを読み込んでいる
- 取引先単位・月単位で不良率を表示している
- 推移はグラフで確認する

## 3. これからExcel解析で確認すること

- 生データの参照パス
- クエリ名と依存関係
- 使用カラム
- 不良率の分子・分母
- 月判定に使用する日付
- 取引先マスタの結合方法
- 除外条件
- 欠損・重複・0除算の扱い
- グラフの初期表示とフィルター

## 4. 人間が確定すべき候補

- 不良率は不良数量÷入荷数量か、不良数量÷検品数量か
- 月は入荷日基準か、検品日基準か
- 返品・交換・部品不足を不良へ含めるか
- 取引先単位と工場単位を分けるか
